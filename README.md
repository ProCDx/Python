# Python course code

Code for every topic of the freeCodeCamp "Learn Python" course
(https://www.youtube.com/watch?v=eWRfhZUzrAc).

- `1_rock_paper_scissors/` - the intro project, built step by step.
  `13_testing_game.py` is the finished game.
- `2_fundamentals/` - one file per fundamentals topic.

Run any file with:

    python 2_fundamentals/03_variables.py

Run files from inside their folder when they import a sibling file
(e.g. `37_modules.py` imports `dog.py`).
